# ✏️ Písmenka

A cute, fast game that helps kids learn to read **Czech handwritten (script) letters**.

**▶ Play: https://pokeypoke.github.io/pismenka/**

A script letter appears and the child presses that key. There's no clock: the score is how many they get right **in a row**. The first mistake shows the correct letter and ends the round.

- Letters are drawn in [Playwrite CZ](https://fonts.google.com/specimen/Playwrite+CZ), a font based on the handwriting taught in Czech schools.
- Choose small letters, capitals, or both. You can also turn on the háčky & čárky (á č ď é ě í ň ó ř š ť ú ů ý ž).
- The missed letter is shown next to its printed form at the end so the child can practise it.
- Correct letters are read aloud in Czech (when the browser has a Czech voice).
- There is an on-screen keyboard for tablets, and it switches on by default on touch screens.
- Best scores are saved in the browser, separately for each letter setting. The game works in Czech or English.

Matching ignores case: for a capital script *Ř*, pressing `ř` counts. Upper/lower case is about recognising the shape, not using Shift.

It's plain HTML/CSS/JS with no build step. Open `index.html` to play locally.
